# First Contact Scope And Exclusions Summary

Status: first-contact draft. Owner approval required before sending.

This summary is intentionally redacted and does not disclose rebuild-level
architecture, full traversal mechanics, source code, full blueprint content,
unredacted SKG/DTN mechanics, EIE implementation mechanics, token/gate internals,
or commercial package/pricing strategy.

## Proposed Review Scope

The proposed review scope is a private, staged, local Desktop V1 technical
validation discussion. The intended review question is whether selected bounded
claims are supported by repository-contained evidence and controlled validation
records.

## Included At Later Confidential Stage

Only after confidentiality acceptance and owner approval, a named reviewer may
receive selected:

- scope and exclusions documents
- claims-to-evidence summaries
- validation reports
- hash/digest manifests
- controlled verification instructions
- guided demo material

## Excluded From First Contact

Do not send at first contact:

- source code
- raw repository archive
- full `reports/` directory
- deployment security notes
- attack/hardening reports
- full blueprint or canon-candidate material
- detailed package manifests
- runtime artifacts
- baselines
- technical install/run commands
- future substrate detail

## Not Claimed

The review request does not claim:

- production certification
- public release
- public deployment
- university validation result
- legal advice
- patent validity
- patent protection completion
- security certification
- government approval
- safety-critical operational approval
- cloud, distributed, node, quorum, or public network operation

## Confidentiality Boundary

Any later technical package must be recipient-specific, watermarked, hash
manifested, and limited to named reviewers. It must include no-student-access,
no-publication, no-redistribution, no-licence, and no-ownership-transfer wording.
