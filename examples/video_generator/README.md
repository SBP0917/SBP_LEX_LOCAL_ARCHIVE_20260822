# SBP Video Studio examples

These files are generated by:

```text
python -m sbp_video samples examples/video_generator
```

General-purpose examples:

- `general-orbital.scene.json` — product-style 3D reveal with hierarchy,
  materials, camera motion, lighting, text, particles, HUD, and timeline markers.
- `general-architecture.scene.json` — modular animated architecture scene.

Cockpit examples:

- `cockpit-rehearsal.scene.json` — deliberately slowed rehearsal/learning traversal.
- `cockpit-full-speed.scene.json` — recorded/full-speed traversal presentation.
- `cockpit-constructed-scenario.scene.json` — clearly labelled constructed scenario.
- `cockpit-read-only-snapshot.json` — detached synthetic input used by the adapter.

Every scene manifest declares `runtime_authority: "NONE"` and
`canonical_runtime_mutation: false`.
