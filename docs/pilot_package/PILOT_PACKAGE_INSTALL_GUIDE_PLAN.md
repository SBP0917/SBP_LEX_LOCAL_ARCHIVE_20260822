# Pilot Package Install Guide Plan

Draft status: plan only. Final install guides are not written in this pass.

## A. Normal Pilot Package Installation Manual

Audience: technical reviewers, university staff, developers, validators.

Future guide sections:

1. Purpose and scope.
2. Desktop V1 boundary and exclusions.
3. Prerequisites.
4. How to obtain the package.
5. Folder setup.
6. Python/runtime setup.
7. Dependency installation or verification.
8. Running the system locally.
9. Running focused validation tests.
10. Optional full pytest instructions.
11. Running `main.py`.
12. Running replay smoke checks.
13. Reading output and logs.
14. Reading evidence manifests.
15. Common errors.
16. What not to touch.
17. When to stop and ask for help.
18. Troubleshooting.
19. Glossary.
20. Support/contact handoff notes.

## B. Plain-English Operator Install Guide

Audience: computer-illiterate or new operators.

Future guide sections:

1. What this package is.
2. What this package is not.
3. What you need before starting.
4. Where to put the folder.
5. How to open PowerShell safely.
6. How to check Python/runtime is available.
7. The exact commands to copy and paste.
8. How to know it worked.
9. How to read simple success/fail messages.
10. What not to click or edit.
11. What files not to delete.
12. Common mistakes and what they mean.
13. When to stop and ask for help.
14. Glossary in plain English.
15. Troubleshooting checklist.

## Shared Requirements For Later Guides

The final guides must:

- avoid production-readiness claims
- avoid public-deployment claims
- preserve local/private Desktop V1 scope
- avoid telling operators to edit runtime code
- separate technical reviewer commands from plain-English operator steps
- clearly say when to stop and ask for help
- include no deployment scripts or installer executables unless separately
  approved in a future task
