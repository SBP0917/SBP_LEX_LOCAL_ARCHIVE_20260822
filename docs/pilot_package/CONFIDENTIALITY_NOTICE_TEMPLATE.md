## Full Notice

This material is confidential owner-controlled SBP-LEX review material. It is
provided only for the limited purpose of private university validation
discussion and technical review by the named recipient.

By receiving this material, the recipient is asked to treat it as confidential
and to not:

- publish it
- present it publicly
- redistribute it
- upload it to any public or internal shared repository
- give it to students, research assistants, teaching teams, classrooms, labs, or
  unapproved staff
- copy it except as needed for the approved review copy
- modify it
- create derivative works from it
- use it for teaching, training, coursework, lectures, or public examples
- reuse it in another project
- claim ownership over it
- treat review access as a licence
- disclose screenshots, excerpts, diagrams, summaries, or command output without
  written owner approval

No licence, ownership transfer, assignment, patent right, copyright licence,
commercial right, reuse right, modification right, derivative-work right,
teaching right, training right, publication right, or redistribution right is
granted.

The material is not a public release, production deployment, external
certification, safety approval, legal opinion, patent validity claim, or
university validation result.

The recipient should return, delete, or stop using the material if requested by
the owner.
