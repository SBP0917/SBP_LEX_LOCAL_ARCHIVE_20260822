# Pilot Package Assembly Plan

Draft status: Phase 19B preparation plan only.

## Purpose

The pilot package is intended to provide a local/private reviewer bundle for
university or technical validation of the SBP_LEX_DUAL_V6 Desktop V1 control
plane evidence.

This plan prepares assembly. It does not create the final package, create a zip
archive, create an installer, deploy the system, or activate runtime expansion.

## Scope

The pilot package may include or summarise existing evidence for:

- Phase 19A closure and implementation
- bounded translator and fixture validation
- Phase 19B evidence and owner-review approvals
- ODA/PVPL/SIM detached support evidence
- audit/replay proof references
- validation reports and reviewer guidance

## Desktop V1 Boundary

The package remains:

- local/private
- bounded
- no active nodes
- no quorum
- no distributed governance
- no cloud runtime assumption
- Dual Adaptive V6 traversal prototype evidence only
- execution-boundary/control-plane validation slice only

## Included Artifact Categories

- Phase 19A reports
- Phase 19B scope/evidence/approval reports
- Phase 19A fixture schemas and examples
- Phase 19A failure-mode register
- selected validation reports
- ODA/PVPL/SIM reports as detached support evidence
- redacted or summarised implementation references
- future install/manual guide placeholders

## Excluded Artifact Categories

- `baselines/`
- missing originals
- unapproved source-lineage V6 documents as authority
- generated `runtime_artifacts/`
- runtime authority files as raw package content without owner approval
- canon-candidate documents as promoted canon
- production or public deployment claims
- node, quorum, distributed governance, or cloud runtime material

## What Is Not Being Claimed

This package does not claim:

- production readiness
- public deployment readiness
- certified post-quantum compliance
- live external publication
- cloud runtime
- distributed governance
- node/quorum operation
- final canon
- runtime authority for ODA, PVPL, or SIM

## What Must Not Be Included

The package must not include:

- `baselines/` as active evidence
- missing originals as authority
- generated caches or bytecode

- final pilot package archive in this preparation pass
