# Desktop V1 Institutional Demonstration and Evidence Pack

## Purpose

This pack supports a controlled demonstration and basic institutional review
of the locked SBP-LEX Desktop V1 operator release.

It explains how to:

- present the local operator console
- distinguish dashboard observation from runtime authority
- review traversal, convergence, execution admissibility, audit, and replay
- collect the existing JSON exports
- repeat the local verification checks
- describe V1 without making production or certification claims

automated capture succeeds. A screenshot records presentation state only; it
does not replace endpoint, test, replay, or source verification.

## Safe use

Run the release on localhost. Use only the fixed approved demonstration action.
Do not present Desktop V1 as a production deployment, autonomous authority,
external government system, cloud service, or formal security certification.
