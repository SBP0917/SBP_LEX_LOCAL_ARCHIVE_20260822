# Investor-Safe Demonstration Flow

## Demonstration posture

This demonstration runs only on the local machine. It does not use cloud
services, perform external execution, connect to live external authority, or
claim production autonomy.

## Controlled flow

1. State that Desktop V1 is a local operator observability console.
2. Show the localhost address and runtime health.
3. Explain that the dashboard reads canonical runtime output and is not an
   execution authority.
4. Run only the fixed approved demonstration traversal.
5. Show Pipeline A and Pipeline B presentation.
6. Show convergence and execution admissibility.
7. Show audit continuity and replay comparison.
8. Show that latest result, replay ledger, and event evidence can be exported.
9. Stop the local runtime after the demonstration.

## Claims boundary

The demonstration does not establish:

- production readiness
- real-world deployment
- external legal or government authority
- autonomous production execution
- cloud availability
- distributed operation
- formal security, assurance, or regulatory certification

It demonstrates a controlled local prototype, its existing deterministic
runtime-backed observations, and repeatable local evidence checks.
