# Desktop V1 Release ZIP Guide

1. Download the repository ZIP from the `main` branch only.
2. Keep the downloaded archive as an original source copy.
3. Rename the release archive to:

   ```text
   SBP_LEX_DUAL_V6_BASELINE_14_DESKTOP_V1_OPERATOR_RELEASE_LOCK.zip
   ```

4. Store a second backup in a separate location.
5. Extract the ZIP before running commands.
6. Do not run the runtime from inside the compressed ZIP.
7. Open the extracted folder that contains `main.py`.
8. Do not edit runtime files inside the baseline backup archive.
9. Keep both Baseline 13 and Baseline 14 backups for recovery and comparison.

For launch instructions, read `START_HERE.md`.
